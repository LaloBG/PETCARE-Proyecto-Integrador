# 🐾 Ecosistema Integrador PETCARE

Proyecto integrador individual que comprende el desarrollo de un ecosistema tecnológico completo enfocado en el cuidado, servicios y comercialización de productos para mascotas.

## 🚀 Módulos del Ecosistema (6 Productos)

1. **01-Laravel-Tienda**: Tienda web backend desarrollada en Laravel con gestión de base de datos MySQL y catálogo interactivo.
2. **02-Angular-PWA-Vacunacion**: Aplicación Progresiva (PWA) construida en Angular para la gestión de solicitudes de vacunación a domicilio y soporte offline.
3. **03-Angular-Sitio-Principal**: Portal web general y centralizado que unifica y enlaza todos los módulos del ecosistema PETCARE.
4. **04-WordPress-WooCommerce**: Tienda virtual administrable montada en entorno local con WooCommerce, gestión de stock y pasarela de demostración (incluye carpeta de evidencias).
5. **05-Angular-Landing**: Landing Page comercial orientada a campañas de bienestar animal y preinscripciones de usuarios.
6. **06-Flutter-App**: Aplicación móvil estructurada en Flutter/Dart para el control personalizado de dosis y medicamentos de mascotas.

## 🛠️ Tecnologías Utilizadas
* **Backend:** Laravel, PHP, MySQL.
* **Frontend / Web:** Angular (Standalone Components), HTML5, CSS3, TypeScript, Tailwind CSS.
* **Móvil / Escritorio:** Flutter, Dart.
* **E-commerce:** WordPress & WooCommerce.
